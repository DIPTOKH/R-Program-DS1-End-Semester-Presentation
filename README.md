# R-Program-DS1-End-Semester-Presentation
Here we scrap a UK gov website to create a dashboard that helps in visual understanding of the data

The project uses the UK Government report AI skills for life and work: labour market and skills projections. The scraper reads
the report's web page, locates Appendix B, extracts selected HTML tables, and converts their contents into structured R data
frames. The Shiny application then makes those data explorable through filters, rankings, plots, summary statistics and
interactive tables.
